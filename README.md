# LocalEats - Qualidade de Software

Repositório destinado às atividades da Unidade Curricular de **Qualidade de Software**, utilizando o projeto **LocalEats** como objeto de análise.

O LocalEats é uma aplicação que conecta usuários a restaurantes locais, permitindo realizar ações como criar conta, acessar o sistema, explorar restaurantes, pesquisar, filtrar, favoritar e realizar pedidos.

## Objetivo

Aplicar os fundamentos de qualidade de software por meio da análise das funcionalidades do LocalEats, considerando as necessidades explícitas e implícitas dos usuários e as características de qualidade do produto.
